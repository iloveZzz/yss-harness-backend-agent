# 条件强制门禁

条件门禁只有命中触发条件才必须裁决；裁剪不能跳过已命中的要求。数量与稳定 ID 读取当前注册表，不把兼容或退役 ID 当作本地执行权限。

governed 可以从原始业务需求完成本地适用 Plan/Spec，也可以复用当前批准的本地或上游输入；冲突回交权威方，不静默改写。正式实现仍须已批准、持久化且当前的 Slice Implementation Contract、必要门禁与允许写范围。

本仓只承担后端交付；另一端角色仅提供只读输入评审，不获得另一端代码写范围。本端完成不代表跨端业务验收，统一管理方核验整体证据。

实施者不能承担命中的独立审查。正式流转核验当前 Context、工程接入与门禁；缺真实决定、必要输入或失效证据时停止受影响工作，有效范围授权继续复用。未触发项记原因，不生成空文档。参见 [[Ticket与流程状态]]、[[Fresh验证与独立审查]]。
