# 模板总览

本仓库是 Harness Agent 的 `template-source`。四角色、五阶段流程为 `harness-entry` → `tactical-design` → `slice-contract` → `slice-implementation` → `verification`。Agent 只读取当前仓库根的 `yss-project.yaml` 与 `AGENTS.md`，不要把父目录或其他 submodule 的入口文件当作本仓路由。

本仓默认作为研发管理仓库，保留流程文档、契约模板、Agent skills 和协作约定。前端 / 后端源码默认位于独立实现仓库；只有用户明确选择本仓库承载实现代码时，才按需创建 `apps/backend/`、`apps/frontend/`。`apps/backend/` 与 `apps/frontend/` 只是项目容器；`app/backend/`、`app/frontend/` 及其子路径禁止作为工程输出。跨仓登记见 [[实现仓库与跨仓库契约]]。

当前 `yss-project.yaml` 为 `schema_version: 1`、`repository_mode: template-source`，走 [[模板维护流程]]，不默认生成具体产品的 Spec、原型、OpenAPI 或垂直切片 Ticket。`project-instance` 按 [[产品研发生命周期]] 分诊。身份判定细则见 [[仓库身份与路由]]。README 只解释入口，不另定义阶段、门禁或技能分层。

单一事实来源不得在 README 或用户指南里另写一套：领域与流程词汇以 `CONTEXT.md` 为准；Agent 入口以 `AGENTS.md` 为准（见 [[Agent入口规则]]）；主阶段、门禁、产物、工作单元和证据以 `docs/process/lifecycle-registry.yaml` 为准；技能清单、哈希和投影目标以 `skills-lock.json` 为准（见 [[技能投影与锁定]]）；技能分层与发现面以 `docs/agents/yss-skill-registry.yaml`（`status: active`）为准。

`.agents/skills` 是跨 Agent 共享技能的权威内容；各平台 root 中的共享技能是生成投影。模板发布阻断门禁是 `scripts/verify-template`（见 [[模板发布门禁与验证]]）。本地知识库走 [[LLM Wiki]]；本仓 wiki-root 为 `.template-source/wiki`。旧入口 `yss-product-lifecycle` 与 `yss-stage-decision` 已退役，迁移路径见 `docs/agents/skill-migrations.md`。
