# 技能投影与锁定

技能投影是从权威共享技能生成、供特定 Agent root 加载的同步副本；锁文件对技能名做 derived 摘录，见 `wiki/raw/skills-lock-names.md`。`.agents/skills` 是跨 Agent 共享技能的唯一权威内容；`.claude/skills`、`.codex/skills`、`.cursor/skills`、`.pi/skills`、`.qoder/skills`、`.trae/skills` 中的同名共享技能是生成投影，禁止分别手工修改。Cursor 的契约运行时入口是 `.cursor/skills`；不得把 canonical `.agents/skills` 与某个平台投影当作同权双入口。

`skills-lock.json` 是技能清单、来源、版本、哈希和投影目标的权威记录，当前 `version` 为 `3`，`canonicalRoot` 为 `.agents/skills`，共享技能 101 个。字段包括 `upstreamHash`、`effectiveHash` 和 `targets`。只属于某个平台的 skill 由锁文件 `platform` 分组记录。

核心技能默认可发现；专项技能由 [[YSS路由与合同编译]] 按影响面选择；试验技能不进入默认闭包。`docs/agents/yss-skill-registry.yaml` 当前 `status: active`，实现合同编译器 / 生命周期必须消费通过校验的 canonical 技能。`llm-wiki` 已在该表登记为 `layer: core`、`maturity: verified`、`instance_default_discoverable: true`，仍不是 `yss-public-skills.json` 条目。

已退役技能不保留物理目录、投影或 lock 条目；历史名称的唯一持久兼容说明是 `docs/agents/skill-migrations.md`。当前已退役入口包括 `yss-product-lifecycle` 与 `yss-stage-decision`，正式编排入口是 `harness-orchestrator`。

YSS 技能的公开发布仓库为 `iloveZzz/yss-spec-dev-skills`。发布阻断校验是 `scripts/verify-template`（见 [[模板发布门禁与验证]]）。创建、修改或退役 skill 走 [[模板维护流程]] 的 `maintaining-skills` 与 L1 / L2 / L3。Matt 上游见 [[Matt技能体系]]；YSS 专项规范见 [[YSS工程技能体系]]。
