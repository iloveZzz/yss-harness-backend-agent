# Standalone evidence baseline

This repository is an isolated Harness Agent distribution created with a single
initial commit. Historical review Markdown files and their source Git history
are intentionally not transferred from the template-source repository.

The evidence index is therefore re-baselined as `pending`. Future template
maintenance reviews must add their Markdown evidence here and refresh the index
with `.template-source/scripts/evidence-index --write --pending` before running
the template release verification.
