# 后端专职模板初始化

本端使用仓库内 `scripts/instantiate-harness`，metadata 为 `.yss-harness-backend.json`；没有已发布专用 npm 包。

从干净的模板检出执行 `node scripts/instantiate-harness --target /absolute/new/project`。模板提交和源文件摘要一同冻结；模板工作树未提交时仅维护测试可使用 `--allow-working-tree`，生成结果标为非发布快照。

已有目录一律拒绝，不能用这个命令原地迁移通用或另一端项目。旧实例仍使用各自入口；升级专职项目先在新目录生成同 profile 候选，再对比并迁移已登记业务资产，保留旧目录回滚。

职责与输入门禁以 [profile](../process/harness-profile.yaml) 和 [接力合同](../process/frontend-backend-delivery.md) 为准。
